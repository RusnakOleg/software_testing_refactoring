# Зауваження та виправлення коду

1. **Назва класу**

   - Було: `humanIMB` (починається з малої літери, неправильна абревіатура).
   - Стало: `HumanBMI` (велика літера + правильна назва).

2. **Назви змінних**

   - Було: `W`, `H`, `imb`.
   - Стало: `weight`, `height`, `bmi` (читабельні назви + стиль lowerCamelCase).

3. **Статичне поле bmi**

   - Було: `private static double imb;` (одне значення для всіх об’єктів).
   - Стало: `private double bmi;` (кожен об’єкт має своє значення).

4. **Назви методів-гетерів/сетерів**

   - Було: `takeW`, `putW`, `takeH`, `putH`. (незрозумілі назви)
   - Стало: `getWeight`, `setWeight`, `getHeight`, `setHeight` (зрозумілі назви).

5. **Метод для визначення результату**

   - Було: `Result()` (статичний, назва з великої літери, нечітка).
   - Стало: `getBmiCategory()` (нестатичний, зрозуміла назва).

6. **Умови в методі Result**

   - Було: використання багато окремих `if`.
   - Стало: використання `else if`.

7. **Повторення коду при обчисленні ІМТ**

   - Було: формула `imb = W / (H * H);` повторювалася у кількох місцях.
   - Стало: винесено в приватний метод `recalculateBmi()`.

8. **Назва змінної в main**

   - Було: `humanIMB humanIMB = new humanIMB(...);` (назва об’єкта співпадає з класом).
   - Стало: `HumanBMI human = new HumanBMI(...);` (зрозуміло і правильно).

9. **Виклик методу результату**

   - Було: `System.out.println(humanIMB.Result());` (статичний виклик).
   - Стало: `System.out.println(human.getBmiCategory());` (через об’єкт).

10. **Покращення**
    - Додав перевірку на коректність введених даних (наприклад, вага > 0, зріст > 0).
    - Виніс клас HumanBMI в окремий файл
